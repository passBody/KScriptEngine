总览全项目跨层关系

入口 → MainWindow 接线 model 全家桶；MainWindow 经 ManagementTree 簇管理 UI；StepListStore→StepList→Step→StepIOWidget 是执行数据主脊；StepRunner 消费 store，HotkeyListener 驱动 runner；actions 各步骤继承 Step 并经 InputControl 模拟输入。

model 层数据核心 · ~5200 行 · 不依赖 PyQt5

.kscp 包存取(KscpPackage) → 变量体系(VariableTree→ProjectVariable→VariableType 策略) → 步骤体系(Step+StepIOWidget/StepStatus，StepList→StepListStore，StepManager 动态导入模板工厂) → 执行器(StepRunner+StepRunnerState) → 热键(HotkeyListener)/设置(Settings) → 日志(LogModel 单例)。

widgets 层UI · ~8200 行 · MainWindow 簇 + 4 棵管理树

MainWindow(双态窗口+执行器接线) 装配 ManagementTree 簇(基类→资源/变量/步骤模板/步骤列表四树+占位树) 与 StepListHost→StepListView→StepCard 卡片链；StepTreeWidget/VariableTreeWidget/ResourceTreeWidget 各带预览面板；LogWidget 经 _LogBridge 接 LogModel；ImageOverlay 全屏图片预览。_ExecBridge 是跨线程信号桥。

actions + libs + tools步骤模板 · 随 .kscp 分发

8 个 Step 子类(按键/鼠标点击/拖动/滚轮/移动/多次点击/延时/输出日志)，各持 Input/Output 数据类；输入模拟步骤经 libs.InputControl 统一发出；MouseClick 附带 _MouseInfoView→_ClickPreview/_ImagePreviewDialog 预览并通过 tools._MarkerDialog 拾取坐标。
