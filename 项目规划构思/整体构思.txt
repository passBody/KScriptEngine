需要一个 结构化步骤列表（一个结构化步骤字典即为一个工程文件.kscp），记录步骤的执行方式
工程文件.kscp - 是一个压缩包其根目录拥有多个json以及其余目录存放资源文件

为此需要 步骤列表 结构数据
	step_list.json
	{
		执行列表1：{
			打开软件：【步骤列表】,
			清理体力：{
					检查体力：【步骤列表】,
					...
				},
			...
		},
		执行列表2：{
			打开软件：【步骤列表】,
			清理体力：{
					检查体力：【步骤列表】,
					...
				},
			...
		}
	}
	拥有访问、添加、删除、移动步骤列表的能力
	可以做到拼接数组 数组中每个步骤都是一个格式化字符串
	`格式化字符串列表`可以构建`QWidget子类对象列表`
	`QWidget子类对象列表`可以构建`格式化字符串列表`

基类步骤：
	生成【输入与输出窗口】-绑定设置输入输出参数函数
	设置输入参数
	设置输出参数
	执行函数

每个子类步骤对象需要满足：
	静态函数 检查：检查格式化字符串是否可生成自身对象
	静态函数 生成：通过格式化字符串生成自身实例对象
	生成格式化字符串
	重写设置输入参数
	重写设置输出参数
	重写执行函数

输入与输出窗口
	拥有访问【全局变量树】的能力
	生成一个QWidget 拥有GUI编写输入与输出参数的能力
	通过格式化数据 如 {{}} 来访问全局变量 内部也可以进行计算
	设置全局变量

全局变量树
	variables.json
	{
		变量名：【变量结构】
		...
		循环系列：
		{
			变量名2：【变量结构】
		}
	}
	拥有访问、添加、删除、移动变量的能力
	在添加变量数据时可以检查（图片路径是否正确）	

变量结构
	拥有访问【全局资源树】的能力
	变量类型：str
	变量数据：xxxxx
	获取实际数据方法  根据变量类型给出实际数据
	生成格式化字符串
	静态方法 通过格式化字符串生成变量对象 （创建时检查是否合规）

全局资源树
	控制 .kscp 文件结构的能力
	拥有访问、添加、删除、移动资源的能力
	读取 .kscp 文件结构的能力
